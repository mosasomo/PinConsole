# PinConsole
PinConsole is a free quick image & GIF search bar for Windows, Linux and MacOS. Press Ctrl+Shift+R anywhere, type, and pick a result with its number. It's copied, or pasted straight into your chat. Search Pinterest, Bing, Tenor GIFs, Wallhaven, Openverse and Google.

The app is free. Optional Pro version unlocks customization features like:
History and favorites sections
Grid customization: more columns, rows and tile sizes
15 themes, ability to create your own custom theme, accent colors and fonts
Several save folders
Personalized Pinterest results by linking your Pinterest account
Saved searches, shape and size filters, custom shortcuts, and a supporter badge

Supports Windows 10/11, Linux and MacOS. Updates are free and install automatically.
(Linux and macOS builds are not as thoroughly tested. Expect some bugs, and please report if you meet any.)

**PinConsole is free of bloatware and contains no malware. It does not collect any telemetry or usage data.**

**Download (free):** [latest release](https://github.com/mosasomo/PinConsole/releases/latest). Get `PinConsole.zip`, unzip it, run `Install.bat`.
